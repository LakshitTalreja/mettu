### IF Specialized RL Training 
The first training that the model undergoes, in this training the model undergoes Reinforcement Learning (RL) for Instruction following (IF) tasks
The output from this stage is a IF expert.

### Stage 2 Multi Teacher On Policy Distillation 
In this stage it considers the trained IF expert as one of the multi teachers and the base model as  the student, the other teacher considered is the DPO teacher 

The base model is passed during training to a domain router that classifies the input given to the model and catergorizes the inputs into two parts IF Prompts and other prompts 
> Domain router : A domain router in machine learning is a specialized, lightweight classifier or embedding-based model that analyzes an incoming input (such as a text prompt, query, or image) and directs—or "routes"—it to the most appropriate downstream domain expert model, specialized small language model (SLM), or specific adapter.

### Token level reverse KL 
Lets start with KL, KL or Kullback-Leibler Divergence is used to measure the difference between two probablity distributions, it considers a target distribution P (teacher) and the approximating distribution Q (student)
Forward KL - P||Q
Reverse KL - Q||P

As reverse KL is zero forcing, it forces the student distribution to align more closely with the selected teacher distribution.

### Policy Update 
The gradients computed from the token-level reverse KL loss are fed back to update the Student network weights directly on its own rollouts.
